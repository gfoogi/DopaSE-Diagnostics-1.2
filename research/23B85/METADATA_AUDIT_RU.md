# Проверка официальной совместимости Dopamine — 23B85

Дата проверки: 12.11.2026. Целевое устройство: iPhone SE 2020 (`iPhone12,8`), A13, iOS 26.1 (`23B85`).

## Что добавлено

В репозитории есть отдельный **безопасный, только читающий** анализатор `tools/audit_upstream_support.py`. Он считывает опубликованный Apple Property List из ветки `3.x` Dopamine и проверяет, фигурирует ли версия/сборка в объявленных диапазонах **одного компонента `momentarius`**.

Пример локальной проверки по заранее сохранённому `Info.plist`:

```sh
python3 tools/audit_upstream_support.py --plist-file Info.plist
```

Опциональная проверка актуального файла из официального репозитория (только HTTPS-чтение):

```sh
python3 tools/audit_upstream_support.py --fetch-official
```

Тесты, не требующие iPhone и сети:

```sh
python3 -m unittest discover -s tests -v
```

**Интерпретация:** `momentariusListedInMetadata: false` — сборка не заявлена поддерживаемой в метаданных компонента. Значение `true` значит лишь, что сборка включена в список, **но не подтверждает** работающий эксплойт, обход защит или джейлбрейк.

## Проверенные источники

- Официальные метаданные: https://github.com/opa334/Dopamine/blob/3.x/Application/Dopamine/Exploits/momentarius/Info.plist
- Официальные релизы: https://github.com/opa334/Dopamine/releases
- Документация по установке: https://ios.cfw.guide/installing-dopamine/
- Исправления в iOS 26.1: https://support.apple.com/en-us/125632

## Итог

Для финальной iOS 26.1 (`23B85`) официальной поддержки Dopamine не подтверждено. Независимая демонстрация джейлбрейка на конкретной модели iPhone SE 2020 не представлена. Нельзя заменить проверку реальной совместимости изменением номера сборки.

Этот код не ищет и не запускает уязвимости, не повышает привилегии, не меняет память ядра и не требует установки на телефон.
